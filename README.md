# DevConf 2026 – Landing Page

A modern and responsive landing page for **DevConf 2026**, a developer conference website. The website provides information about conference speakers, ticket pricing, and an AI Innovation Lab.

## 🌐 Live Website

[Visit DevConf 2026](https://junaid-redart.github.io/DevConf-Landing-Page/)

## 📂 GitHub Repository

[DevConf-Landing-Page](https://github.com/Junaid-redart/DevConf-Landing-Page)

## ✨ Features

- **Navigation Bar:** Simple navigation with a registration button.
- **Hero Section:** Attractive banner with a conference introduction.
- **Meet the Speakers:** Profiles of four technology speakers.
- **Pricing Section:** Three ticket plans – Standard, Pro, and Team.
- **AI Innovation Lab:** A creative AI-themed section with feature cards and visual elements.
- **Footer:** Copyright information and useful links.
- **Responsive Design:** Optimized for desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Inter)
- CSS Grid
- CSS Flexbox
- CSS Media Queries
